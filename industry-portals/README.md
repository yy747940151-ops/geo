# 行业门户发布试点

本目录为独立试点配置，未接入原五平台发布器。所有平台默认禁用自动提交，电话默认不出现在标题、正文或图片中。

## 验收步骤
1. 用户通过正式入口登录并完成必要的企业认证，不收集密码或验证码，不上传Cookie。
2. 确认真实企业服务类目、免费额度、正文与联系字段的400电话许可、平台自动化规则；存在冲突则遵循更严格规则或向官方核实。
3. 仅在对应栏目允许后提交单条真实服务稿或行业文章；拒绝则记录原因，不换类目绕审或重复提交。
4. 核对审核结果、公开页面、电话显示及图片，记录实际URL和证据；未公开不标为成功。
5. 审核通过且允许自动化才逐个平台启用独立适配器。不得改变原五平台任务、发布器或主分支。

首轮优先八方资源网。现有全部渠道未完成登录、免费额度实测或实际发布；规则表中unknown表示不得加电话。
